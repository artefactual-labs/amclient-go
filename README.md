# amclient

[![PkgGoDev](https://pkg.go.dev/badge/go.artefactual.dev/amclient)](https://pkg.go.dev/go.artefactual.dev/amclient)

This repository provides the `go.artefactual.dev/amclient` module.

The API is still **experimental**, breaking changes MAY occur.

## Go support

This project is maintained on a best-effort basis. When its Go baseline is
updated, it aims to follow the [Go release policy] by supporting the two latest
stable releases and, where practical, the most recently deprecated release for
an additional six months. The `go.mod` directive and versions tested in CI are
the authoritative current support matrix. Older Go versions may work but are
not supported.

[Go release policy]: https://go.dev/doc/devel/release#policy
